# Stock Trading Platform

A Java console application simulating a 
real stock trading environment using OOP.

## Features
- View live simulated market prices
- Buy & sell stocks
- Portfolio performance tracking  
- Complete transaction history
- 7 stocks — TCS, Infosys, Wipro, 
  Reliance, HDFC, Google, Amazon
- Starting balance: Rs.1,00,000

##Tech Stack
Java | OOP | Collections | HashMap | ArrayList

##Classes
- Stock — represents each stock
- Portfolio — manages holdings & balance
- StockTradingPlatform — main program

## How to Run
javac StockTradingPlatform.java
java StockTradingPlatform
